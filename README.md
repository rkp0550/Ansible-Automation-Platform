# Ansible Automation Platform (AAP) Learning Journey

## Overview

This repository is designed to help engineers, administrators, and developers learn and practice using Red Hat Ansible Automation Platform (AAP).

The goal is to provide a structured learning path covering:

- Ansible fundamentals
- Playbook development
- Roles and Collections
- Automation Controller
- Event-Driven Ansible (EDA)
- Automation Hub
- Configuration as Code
- CI/CD integration
- Enterprise automation best practices

---

## What is Ansible Automation Platform?

Ansible Automation Platform (AAP) is an enterprise automation platform that enables organizations to automate:

- Infrastructure provisioning
- Operating system administration
- Application deployment
- Cloud operations
- Security workflows
- IT Service Management (ITSM)
- Event-driven operations

AAP extends Ansible by adding:

- Automation Controller
- Automation Hub
- Event-Driven Ansible
- Automation Mesh
- Execution Environments
- Enterprise RBAC and Governance
